# Loan Approval Predictor

A Machine Learning project that predicts loan approval status.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Features
- Loan prediction
- Logistic Regression
- Streamlit UI

## Run Project

pip install -r requirements.txt

streamlit run main.py
this project includes loan approval using machine learning.
